Dados obtidos via API SportDB. A sincronização está pausada por custo da API; o código e os dados já coletados continuam disponíveis.

Análise de desempenho de times e identificação de talentos no Brasileirão Série A.

Acessar Plataforma Ver no GitHub

Problema

Analisar o desempenho dos times da Série A e identificar jogadores que se destacam pouco na visibilidade, mas bem nos números.

Dados

O dashboard usa dados da API SportDB, com sincronização pausada. A plataforma acompanha 20 times e mais de 500 jogadores catalogados.

Decisões técnicas

  • O Garimpo é o modelo que avalia jogadores por posição, com métricas por 90 minutos.
  • Ele destaca jogadores com score alto e poucos minutos jogados, que é onde o talento tende a passar despercebido.
