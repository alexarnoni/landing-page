EV+ Sports Analyzer

Bot que analisou odds em 200+ ligas, calculou valor esperado e enviou alertas no Telegram, com histórico em SQLite. Projeto encerrado.

Ver no GitHub

Problema

Comparar odds de eventos esportivos em muitas ligas e identificar quando o valor esperado é positivo (EV+).

Dados

Odds de 200+ ligas de mais de 50 países, obtidas via Odds API por um scheduler que varria a cada 2 minutos. O histórico ficava em SQLite.

Decisões técnicas

  • O bot calculava o valor esperado de cada oportunidade e enviava alertas automáticos pelo Telegram.
