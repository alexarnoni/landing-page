Acervo

Data engineering and analysis of my own music listening history, from 2014 to 2026.

Open Dashboard View on GitHub

Problem

How has my listening behavior changed over 12 years? Acervo answers it with my own music listening history, from 2014 to 2026.

Data

The base is about 413,000 raw events from Spotify's extended streaming history export (2014-2026). Cleaning separated podcasts, removed noise and duplicates, and discarded IP and location.

Data quality

  • The skip field came back zeroed for 2017-2021, so the metric is now derived from the forward button.
  • 768 plays from someone else (a borrowed account) were removed by date windows.

Technical decisions and trade-offs

  • A Python pipeline with pandas models the result as a star schema, with key validation and tests.
  • The analyses include eras detected automatically by dynamic programming with Hellinger distance, Kaplan-Meier by artist generation, and rediscoveries.
  • The same model is ready for Power BI (M queries and DAX measures) and feeds a read-only FastAPI API.
  • The same model feeds a Power BI report, already delivered, and a read-only FastAPI API.
  • The published site is static, reading JSON generated from the cleaned data. The API only runs locally.

Result

Two findings already shown on the published dashboard: the top artist's share dropped from 36% (2020) to 10% (2025), and new artists per year rose from 76 (2019) to 401 (2025).

Limitations

  • The 2017-2021 skip rate is derived, not measured: the original field was empty in those years.
  • Only aggregated results are published. The raw Spotify export never goes into the repository.
