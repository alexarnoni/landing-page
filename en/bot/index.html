EV+ Sports Analyzer

Bot that analyzed odds across 200+ leagues, calculated expected value and sent Telegram alerts, with history in SQLite. Project closed.

View on GitHub

Problem

Compare odds for sports events across many leagues and identify when expected value is positive (EV+).

Data

Odds from 200+ leagues in more than 50 countries, fetched through the Odds API by a scheduler that scanned every 2 minutes. History was kept in SQLite.

Technical decisions

  • The bot calculated the expected value of each opportunity and sent automatic alerts through Telegram.
