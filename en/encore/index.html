Encore

Data pipeline that measures how seven bands use their own discography in live shows, built from setlist and discography data.

Open Platform View on GitHub

Problem

How does a band use its own catalogue live over a career? Encore analyzes Arctic Monkeys, Oasis, Linkin Park, Twenty One Pilots, Muse, Metallica and Avenged Sevenfold through three metrics: repertoire age, rotation between shows and song survival (Kaplan-Meier).

Data

Setlists come from setlist.fm and discography comes from MusicBrainz. In the scoping phase, setlist.fm had 9,499 mapped shows for the seven bands (setlist coverage ranges from 75% to 97% across them), and the scope has 59 studio albums.

Raw setlist.fm data is deleted at the end of every pipeline run. Only aggregated results are kept and published.

Technical decisions and trade-offs

  • A monthly Airflow DAG orchestrates extraction, validation, dbt Core transformation and the survival analysis in Python.
  • A guard test fails the build if a setlist_id column ever appears in the analytics schema, so no per-show data leaks into the published layer.
  • The site build (Jinja2 and SVG) fails on a missing translation or a broken link.
  • The pipeline runs on the VM, and the site is static on Cloudflare Pages, with no cost for infrastructure running 24 hours a day.
  • The published site is static: there is no API or backend running.

Result

The site publishes the three metrics per band. One example is Metallica's pattern: with each new album the repertoire gets younger for a while, then ages again until the next release. The test suite has 318 passing tests (14 are skipped when the test database is not running).

Limitations

  • The site is not rebuilt automatically after each pipeline run. Publishing is a manual step.
  • There are seven bands, chosen for an interesting history and good data coverage, not a sample of the universe of bands.
