Acervo

Engenharia e análise de dados sobre o meu próprio histórico de escuta musical, de 2014 a 2026.

Acessar Dashboard Ver no GitHub

Problema

Como meu comportamento de escuta mudou em 12 anos? O Acervo responde com o meu próprio histórico de escuta musical, de 2014 a 2026.

Dados

A base são cerca de 413 mil eventos brutos do export estendido do Spotify (2014-2026). A limpeza separou os podcasts, removeu ruído e duplicados e descartou IP e localização.

Qualidade de dados

  • O campo de skip veio zerado em 2017-2021, então a métrica passou a ser derivada do botão avançar.
  • 768 plays de terceiros (uma conta emprestada) foram removidos por janelas de data.

Decisões técnicas e trade-offs

  • Um pipeline em Python com pandas modela o resultado em esquema estrela, com validação de chaves e testes.
  • As análises incluem eras detectadas automaticamente por programação dinâmica com distância de Hellinger, Kaplan-Meier por geração de artistas e redescobertas.
  • O mesmo modelo está pronto para Power BI (queries M e medidas DAX) e alimenta uma API FastAPI somente leitura.
  • O mesmo modelo alimenta um relatório em Power BI, já entregue, e uma API FastAPI somente leitura.
  • O site publicado é estático, lendo JSON gerado a partir dos dados tratados. A API roda só localmente.

Resultado

Dois achados que já aparecem no dashboard publicado: a participação do artista mais ouvido caiu de 36% (2020) para 10% (2025), e os artistas novos por ano subiram de 76 (2019) para 401 (2025).

Limitações

  • A taxa de skip de 2017-2021 é derivada, não medida: o campo original estava vazio nesses anos.
  • Só resultados agregados são publicados. O export bruto do Spotify não vai para o repositório.
